Cifrado César Simétrico & Aritmética Modular

01. Fundamento

Un caso elegante del cifrado César donde el desplazamiento es exactamente la mitad del alfabeto (13 de 26).

E(x) = (x + 13) mod 26

Al ser simétrico, la misma función cifra y descifra. Es una involución matemática.

02. Algoritmo

// Flujo de transformación
1. char → ASCII
2. if (A-Z) val = (val - 65 + 13) % 26 + 65
3. if (a-z) val = (val - 97 + 13) % 26 + 97
4. ASCII → char

03. Contexto

Seguridad Nula

No apto para datos sensibles. Su uso es cultural: ofuscación de spoilers, soluciones de acertijos o chistes en foros públicos.

Curiosidad: "ROT26" es una broma geek; rotar 26 veces devuelve el texto original sin cambios.
