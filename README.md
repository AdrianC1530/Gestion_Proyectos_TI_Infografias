# Gobierno y gestión de proyectos de TI: infografías

Páginas web e infografías elaboradas para las materias de **gobierno y gestión de proyectos de TI**.

## Contenido

- Componentes de un sistema de gobierno de TI.
- Diagrama de ruta crítica (CPM).
- Infografía de síntesis sobre gobierno y gestión de proyectos.
- Material de apoyo (materiales y métodos, reporte de proyecto).

## Tecnologías

HTML, CSS, Python.

## Cómo verlo

Abrir cualquiera de los archivos `.html` en el navegador.
